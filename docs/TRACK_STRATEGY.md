# Track strategy from the two supplied UB Hacking PDFs

Sources: “How To UB Hacking 2026(1).pdf” (guide last updated October 28, 2026) and “Radial Atoms - UB Hacking 2026 Radial Ventures Track.pdf”, supplied by Ranveer. Event facts below describe those documents, not a promise of eligibility or a verified live schedule.

## Focus the product

**Panda: a voice-guided recovery companion that turns a reviewed care plan into observable exercise progress and a clinician handoff.**

Radial explicitly permits phone/laptop cameras and does not require custom hardware. Its physical-world connection plus meaningful AI requirement fits an actual camera pose model: sense movement → interpret landmarks/confidence → count an estimated repetition or pause → save a report for clinician review. Camera preview, a pretty avatar or manually generated rep counts alone do not demonstrate that loop. A numerical simulated report in the starter is an integration fixture, not a model of a physical system or an AI achievement.

## Submission and provenance

The guide asks one team member to create a GitHub Classroom team at https://ubh.ac/github-classroom; teammates join it. It requires a YouTube demo video under three minutes and says only the first three minutes are reviewed. It prints a Sunday November 8 submission cutoff of 11:30 AM and hacking end of 1:30 PM, labelled EDT. Check current event announcements for operational times: the document links older 2024 rules and its timezone label should not be used to silently infer a UTC deadline.

Radial requires new project software during the hacking period, permits public libraries/models/datasets, and requires disclosure of prior components and simulated/mock data. This package replaces an earlier planning-session scaffold. Do not claim all baseline code was newly authored by the three teammates during a verified eligible window. Keep Git history and write an honest list in `docs/DISCLOSURE.md` of reused scaffolding, AI assistance, new team implementation, public model/library versions and exactly which results are live versus synthetic.

The guide mentions a hardware lab, while Radial says bring hardware unless availability is confirmed. The present plan uses existing phones/laptops, so custom equipment is not a dependency.
